小米6刷机

发表于2026-01-03|更新于2026-01-10|移动安全
|总字数:1.4k|阅读时长:6分钟|浏览量:

背景

设备

  1. 机型：MI6（sagit）
  2. 处理器：骁龙835
  3. 存储空间：64GB
  4. 原系统：MIUI11/Android9

意义

Android9确实比较老，Google在安卓10/11上加入了一些新东西，某几个别的app可能没法兼容到Android9，总之，由于各个原因，现在将LineageOS(22.2)/Android15刷入到MI6机器上，做个记录，后续可做参考。

资源

  1. WIN10/WIN11（准备好platform-tools）

  2. 小米官方BL解锁工具：https://cdn.cnbj1.fds.api.mi-img.com/flash-tool/miflash_unlock_7.6.727.43.zip

  3. 刷机资源（lineageOS-Mi6）：lineage-22.2-20260102-nightly-sagit-signed.zip（卡刷包）、recovery.img（可选）、boot.img

  4. 搞机助手：主要用来解决fastboot驱动问题，懒人也可以用来代替一些刷机指令

  5. TWRP：TWRP-Mi6（本次采用TWRP进行刷机）

BL解锁

  1. 用USB线将手机和电脑相连

  2. 插入有效SIM卡，设置里面登陆小米账号

  3. 进入开发者选项，开启USB调试

  4. 关闭WiFi，保证只通过数据流量进行网络通信，进入设备解锁状态，绑定设备

  5. 启动搞机助手，安装相关驱动

  6. 验证环境是否成功

  7. 启动miflash_unlock.exe，登录绑定的手机号

  8. 同意所以协议后，点击解锁，等待进度条到100%（比较快，如果卡在50%，可能是上面的驱动没有安装好或者其他原因）

  9. 自动或者手动重启，进开发者选项，查看设备解锁状态，完~

刷机

Android分区名称 说明 风险
Boot 包含Linux内核和ramdisk（初始化内存磁盘），用于引导系统启动。刷入自定义内核或替换 boot.img 时需要操作此分区。 错误刷入可能导致无法开机。
System 存放 Android 操作系统的主要文件（如 framework、app、库等）。刷入 ROM 时通常要刷写 system.img。 如果空间不足或文件不兼容，会导致系统无法正常运行。
Vendor 存放芯片厂商提供的驱动和固件（如高通、联发科的硬件支持文件）。刷入某些 AOSP 或定制 ROM 时需要刷写 vendor.img，确保硬件正常工作。
Recovery 包含一个小型的独立系统，用于恢复、刷机、备份等操作（如 TWRP、CWM）。可独立刷写第三方 recovery。 刷机前常需先刷入 custom recovery 来刷 ROM
Data 存储用户数据，包括应用、设置、媒体文件等（相当于 Windows 的“用户文件夹”）。执行“双清”（wipe data/factory reset）或“三清”时会清除此分区 刷机前建议备份，否则会丢失所有个人数据。
Cache 系统缓存区，提升应用运行效率。刷机过程中通常会被清空，一般无需单独备份。
EFS 存储设备的IMEI、序列号、基带信息等关键硬件识别数据。 绝对不能乱刷或丢失！ 一旦损坏可能导致无信号、IMEI 丢失，手机变成“砖”。建议在刷机前完整备份 EFS。
Userdata 在某些文档中 userdata 与 data 分区含义相近，但在分区表中可能单独列出。需注意不同厂商命名差异。
Bootloader 虽非传统“分区”，但它是刷机的起点。通常需要解锁（unlock）bootloader 才能进行刷机。 解锁后，只有好处没有坏处
